# ein

## Examples

- Ich brauche einen Termin beim Arzt. :: I need an appointment with the doctor.
- Meine Tochter hat eine Frage an die Lehrerin. :: My daughter has a question for the teacher.

## Notes

*ein* changes with gender and case: *ein Termin*, *einen Termin*, *mit einem Termin*; *eine Frage*. The table is in the grammar entry *Adjektivendungen*.
