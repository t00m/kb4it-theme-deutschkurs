# doch

## Examples

- Kommen Sie doch morgen um neun Uhr. :: Do come tomorrow at nine o'clock.
- Kommst du nicht mit? Doch, ich komme mit. :: Aren't you coming? Yes, I am.

## Notes

*doch* answers "yes" to a negative question. In a request it makes it friendlier.
