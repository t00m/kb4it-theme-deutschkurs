# Lehrerin

## Examples

- Die Lehrerin hat uns eine Nachricht geschrieben. :: La maestra nos ha escrito un mensaje.
- Ich rufe morgen die Lehrerin an. :: Mañana llamo a la maestra.

## Notes

El femenino se forma con *-in*: *der Lehrer*, *die Lehrerin*.
