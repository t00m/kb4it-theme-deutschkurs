# aber

## Examples

- Ich möchte kommen, aber ich habe keine Zeit. :: I would like to come, but I have no time.
- Der Termin ist früh, aber das ist kein Problem. :: The appointment is early, but that is no problem.

## Notes

After *aber* the word order does not change: *aber ich habe*.
