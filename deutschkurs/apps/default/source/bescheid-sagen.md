# Bescheid sagen

## Variants

- Sag mir Bescheid! :: Let me know!
- Sagen Sie mir bitte Bescheid. :: Please let me know. (formal)

## Usage

When you promise to tell someone later. The person is in the dative: *mir*, *dir*, *Ihnen*.
