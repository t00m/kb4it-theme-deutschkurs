# für

## Examples

- Das Geld ist für den Ausflug. :: The money is for the trip.
- Ich habe ein Geschenk für meinen Sohn. :: I have a present for my son.

## Notes

*für* always takes the Akkusativ: *für den Ausflug*, *für meinen Sohn*.
