# Ausflug

## Examples

- Am Freitag macht die Klasse einen Ausflug in den Zoo. :: On Friday the class goes on a trip to the zoo.
- Für den Ausflug braucht mein Kind eine Brotdose. :: For the trip my child needs a lunch box.
