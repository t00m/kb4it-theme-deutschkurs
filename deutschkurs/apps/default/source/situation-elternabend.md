# Elternabend

The parents of the class meet the teacher in the evening, a few times a year.

## I can

- [ ] Ich kann sagen, ob ich zum Elternabend komme. :: I can say whether I am coming to the parents' evening.
- [ ] Ich kann mich den anderen Eltern vorstellen. :: I can introduce myself to the other parents.
- [ ] Ich kann der Lehrerin eine Frage zum Ausflug stellen. :: I can ask the teacher a question about the trip.
